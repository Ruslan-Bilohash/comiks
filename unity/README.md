# Komiks·Lab World — 3D open world (Unity 6 + URP)

Процедурний острів у норвезькому стилі: фйорд, гори зі снігом, ліс, село з вогнищем, море,
цикл дня й ночі та гравець від третьої особи. Усе будується **у коді** при запуску — жодних
ручних ассетів, префабів чи ручного розставляння.

## Як запустити

1. У Unity Hub: **Add ▸ Add project from disk** → папка `unity/` (Unity 6.3, `6000.3.11f1`).
2. Дочекайся імпорту. Скрипт `UrpAutoSetup` сам створить і призначить URP-ассет
   (`Assets/Settings/`). Якщо щось пішло не так — меню **Comiks ▸ Налаштувати URP**.
3. Меню **Comiks ▸ Створити сцену світу** → зберігається `Assets/Scenes/World.unity`.
   (Можна й без сцени: у будь-якій сцені натисни **Play** — світ з'явиться сам.)
4. **Play**.

## Керування

| Клавіша | Дія |
|---|---|
| WASD | рух |
| Shift | біг |
| Space | стрибок (у воді — виплигнути) |
| Миша / колесо | камера / зум |
| T (тримати) | час іде в 40 разів швидше |
| Esc / клік | відпустити / захопити курсор |

## Що всередині

| Файл (`Assets/Scripts/World/`) | Що робить |
|---|---|
| `WorldBuilder.cs` | збирає все разом; тут же налаштування (seed, розмір, кількість дерев) |
| `HeightField.cs` | карта висот: берег, гори, фйорд, плато під село |
| `TerrainFactory.cs` | Unity Terrain + розмальовка (пісок / трава / скеля / сніг) за висотою й ухилом |
| `TextureFactory.cs` | процедурні текстури, що безшовно повторюються |
| `WaterSurface.cs` | море з плинною текстурою |
| `VegetationFactory.cs` | ялини, берези (чанками по 100 м) і каміння, з колізіями |
| `VillageFactory.cs` | 8 будинків, дерновий дах, вікна, що світяться вночі, вогнище |
| `DayNightCycle.cs` | сонце, місяць, небо, туман, амбієнт, підводний туман |
| `ThirdPersonController.cs`, `OrbitCamera.cs` | гравець (ходьба, біг, стрибок, плавання) і камера |
| `InputProxy.cs` | ввід — працює зі старим Input Manager і з Input System |

Налаштування світу — на компоненті `WorldBuilder`: `seed` (інший сід — інший острів),
`worldSize`, `worldHeight`, `treeCount`, `rockCount`.

## Нотатки

- `.meta`-файли з'являться при першому відкритті в Unity — закоміть їх.
- Проєкт написано без запуску редактора: якщо при імпорті Unity покаже помилку компіляції,
  надішли текст помилки — виправлю.
- Ідеї для наступних кроків: NPC із діалогами норвезькою (зв'язок із комікс-уроками),
  північне сяйво, зорі вночі, пірс і човен, дощ/сніг, міні-карта.
